# Hello Elementor Child — functions.php

Kopie van `functions.php` van het actieve child-theme "Hello Elementor Child" op grovia.nl
(WordPress-map `hello-theme-child-master`). Dit bestand bevat de maatuitvraag voor het tenue
(shirt/broekje/sokken), de klikbare variatie-pillen en de Vereniging/Team- en kindvelden.

**Er is geen deploy-pipeline.** Live bijwerken gaat via
Weergave → Thema bestand editor → Hello Elementor Child → functions.php.
Ververs die pagina altijd vlak vóór een wijziging (stale-tab-incident 2026-08-05, zie
`docs/superpowers/plans/2026-08-05-minimove-strippenkaarten.md`, Spoor 5).

Baseline: stand van de live site op 2026-09-23, door Max geplakt. Wijzigingen daarna staan in git.
